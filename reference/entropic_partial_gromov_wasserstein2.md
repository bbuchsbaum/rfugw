# Entropic Partial Gromov-Wasserstein Objective Value

Entropic Partial Gromov-Wasserstein Objective Value

## Usage

``` r
entropic_partial_gromov_wasserstein2(...)
```

## Arguments

- ...:

  Additional arguments. Unused extras are rejected when the solver uses
  `.reject_unused_dots()`; otherwise they are forwarded to the primary
  solver.

## Value

Entropic partial GW value.
