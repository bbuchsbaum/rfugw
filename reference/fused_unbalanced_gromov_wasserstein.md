# POT Alias for Fused Unbalanced GW

POT Alias for Fused Unbalanced GW

## Usage

``` r
fused_unbalanced_gromov_wasserstein(...)
```

## Arguments

- ...:

  Additional arguments. Unused extras are rejected when the solver uses
  `.reject_unused_dots()`; otherwise they are forwarded to the primary
  solver.

## Value

A list with `pi_samp`, `pi_feat`, `fugw_cost`, `linear_cost`,
`iterations`, and `error`.
