# Entropic Semirelaxed Gromov-Wasserstein Objective Value

Entropic Semirelaxed Gromov-Wasserstein Objective Value

## Usage

``` r
entropic_semirelaxed_gromov_wasserstein2(...)
```

## Arguments

- ...:

  Additional arguments. Unused extras are rejected when the solver uses
  `.reject_unused_dots()`; otherwise they are forwarded to the primary
  solver.

## Value

Numeric scalar semirelaxed GW value.
