# Fused Gromov-Wasserstein Barycenters

Convenience alias to `entropic_fused_gromov_barycenters`.

## Usage

``` r
fused_gromov_barycenters(...)
```

## Arguments

- ...:

  Additional arguments. Unused extras are rejected when the solver uses
  `.reject_unused_dots()`; otherwise they are forwarded to the primary
  solver.
