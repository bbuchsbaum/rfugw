# Inspect Transported Mass

Inspect Transported Mass

## Usage

``` r
transport_plan_mass(plan, margin = c("total", "source", "target"))
```

## Arguments

- plan:

  Transport plan, operator, result, dense matrix, or sparse matrix.

- margin:

  `"total"`, `"source"` (row masses), or `"target"` (column masses).

## Value

Numeric scalar or vector.
