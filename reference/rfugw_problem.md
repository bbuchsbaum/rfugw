# Extract the explicit transport problem contract

Extract the explicit transport problem contract

## Usage

``` r
rfugw_problem(x)
```

## Arguments

- x:

  An `rfugw_transport_problem` or a result from
  [`transport_solve()`](https://bbuchsbaum.github.io/rfugw/reference/transport_solve.md).

## Value

An `rfugw_transport_problem`.
